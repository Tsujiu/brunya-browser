# Segurança — Brunya Browser

Não abra issue pública para vulnerabilidade. Uma issue pública mostra o
defeito antes de existir correção.

Envie o relato para `security@brunyabrowser.org` com:

- commit ou versão do Brunya e o sistema em que ocorreu;
- o que é preciso fazer para repetir o problema;
- o efeito que você observou.

O projeto pretende confirmar o recebimento em até 48 horas e combinar a
divulgação depois que houver correção. Esse prazo é uma meta operacional,
não uma garantia contratual.

O modelo de ameaça usado no desenvolvimento está em
[docs/SECURITY.md](docs/SECURITY.md). Em caso de divergência sobre como
reportar, vale este arquivo.

A licença do repositório não autoriza testar o programa contra pessoas
ou sistemas sem permissão de quem os controla.
